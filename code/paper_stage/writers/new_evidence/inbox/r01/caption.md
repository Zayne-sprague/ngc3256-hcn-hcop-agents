**Figure F1** (`f1_hcn_hcop_profiles.png` and `.pdf`; plotted values in `f1_values.csv`; scripts `f1_compute.py`, `f1_plot.py`).
HCN/HCO+ 3-2 radial profiles of N (orange) and S (blue) from the ALMA 2017.1.00379.S Xb4b 12-m cubes (native beam 0.246x0.237", spw27 HCN, spw25 HCO+), convolved in the image plane to a common **circular 0.30" beam**, for the annuli 0-.15/.15-.25/.25-.5/.5-1/1-1.5/1.5-2/2-3" (plotted at the mid-radius; top axis in pc, 1" = 194 pc). Annuli beyond 0.7" use only the half-plane facing away from the other nucleus. The quantity is the ratio of moment-0 maps (Jy/beam km/s, same beam) over **+-350 km/s** about 2780 km/s; multiply by (nu_HCO+/nu_HCN)^2 = 1.013 for a strict T_B ratio (N/S unaffected).
- **Filled symbols, error bars = statistical (off-line pseudo-moment null scatter, 5 line-free windows at +-900..1100 km/s) added in quadrature with the baseline/window term** (max deviation of the ratio between the adopted per-pixel median baseline of line-free channels at 600-1500 km/s from line centre, and median 600-1500 with +-200 or +-500 km/s line windows, and a per-pixel linear baseline with +-350). The array and residual/restored terms are not in the top-panel bars.
- Open symbols: Xb4d (0.94x0.74" native, 12-m) at a 1.05" beam, same recipe (so the 0-.15" and .15-.25" Xb4d points are sub-beam annuli, shown only for the comparison). Small triangles: team-a q64 (p0065, `img_ratios.csv`) 0.30" Xb4b values, median over their baseline windows A,B,C (bar = min-max), with **different annuli** (0-.1/.1-.25/.25-.5/.5-1/1-2/2-3") and a different baseline set (-850..-450 and +450..+600 km/s), plotted at their own mid-radii with +-7% offsets.
- Lower panel: N/S per annulus (black, stat error bar) and the error budget as side bars: stat; baseline/window; array = |N/S(Xb4b 1.05")/N/S(Xb4d 1.05") - 1| x N/S per annulus; residual/restored = 3.5% low-bias estimate from tclean residual/restored (N 0.02-0.04, S 0.05-0.08), measured only for the r<0.5" cores at ~1.3" (s414) and applied to r<0.5" only (absent beyond).
- Key numbers (0.30", med350): N 0.985/0.967/0.868/0.648/0.342/0.245/0.32; S 0.449/0.418/0.395/0.321/0.371/0.502/0.62; N/S 2.19/2.31/2.20/2.02/0.92/0.49/0.52. Core r<0.25": N/S = 2.26 (+0.11/-0.15) (stat 0.09, baseline 0.05, array 0.03, resid/restored 0/-0.08), r<0.5": 2.21 (p0064, out/q64r2/final_budget.txt).
- **Beam:** the 0.25" native beam is marked (bar); **r<0.15" is unsupported** (grey; inside the native beam; the inner annulus is shown for completeness only). Beyond ~1" the ratios are baseline-dominated (budget bars larger than the N/S signal; the 2-3" annulus, new here, has stat error 1.5 on N/S and is not meaningful, and the N/S<1 at 1-3" is an artefact of baseline/low S/N, not a result).
- **Caveat: image plane only.** No Xb4b visibilities exist (restore OOM x4), so there is no uv-matched or 12m+7m check below 1"; flux recovery at <1" is inferred from the Xb4b/Xb4d ratio of ratios at 1.05" (0.98-0.99 inside 1"), no JvM correction.
