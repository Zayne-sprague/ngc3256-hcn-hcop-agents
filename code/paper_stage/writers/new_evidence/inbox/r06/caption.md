**Figure F4** (`f4_radex_abundance.png/.pdf`; data `f4_profile_values.csv`, `f4_bayes_factors.csv`; scripts `f4_profile.py`, `f4_plot.py`; model/likelihood: `scripts/s353_q57_joint_bracket.py`, `s356_q57_physical.py`, outputs `out/q57/`; p0062).
**Upper panel:** profile likelihood of the joint N+S one-zone RADEX fit under the *equal-abundance-ratio* hypotheses (A = N(HCN)/N(HCO+) equal at N and S): delta(-2lnL) = delta chi2 above each hypothesis' own best fit versus the model J=1-0 HCN/HCO+ N/S contrast, maximised over the other parameters. Orange = H_exc (only Tk, n, beam filling differ), blue = H_col (also N(HCO+) free per nucleus). Thick solid = 12C/13C 40-100 (log-flat), no density constraint (best fits at contrast 1.10 for H_exc, 1.15 for H_col, 7.7 and 5.0 above the unconstrained best model H_full; delta chi2 <= 1: 1.05-1.20 and 1.05-1.26; <= 4: 0.95-1.26 and 0.87-1.38); dotted = log n >= 3.8 (H_exc 1.05-1.20/0.95-1.26; H_col 0.95-1.15/0.79-1.26); dashed = 12C/13C 20-200 (H_exc 1.00-1.32/0.91-1.51). Horizontal dash-dot lines: delta chi2 = 1 and 4. Grey bar: observed 1-0 contrast 1.448+-0.015 (+-150 km/s, 2.2" beam, stat only; p0036 s192, comb h150; the +-350 km/s value is 1.467+-0.022). Pink band: best-fit contrasts with equal A, 1.09-1.13 (1-0; H_exc 1.09, H_col 1.13). Strip: observed 3-2 contrast 1.503+-0.017 and the best-fit equal-A 3-2 contrasts 1.23-1.35 (best-fit values only; **no 3-2 profile was computed**). At the observed 1.45 the profile is 11.0 (H_exc) and 6.0 (H_col) above the own minimum for 12C/13C 40-100 (18.7 and 11.0 above H_full), 4.5 (H_col) and 3.0 (H_exc) for 20-200 (the curves are bin envelopes, ~0.02 dex binning; the profiles are not smooth because the grid is coarse). The post's 'about 2 sigma' (p0062) refers to the best-fit delta chi2 of the hypothesis (7.7/5.0), not to forcing 1.45.
**Lower panel:** Bayes factor of H_abun (same Tk, n, N(HCO+), 12C/13C at N and S; only A differs) over H_exc for **48 cells** (3 error models x 2 12C/13C priors x 8 physical priors; `out/q57/s356_*.txt`): halved errors (green) 371-2200, default (orange) 16-44, doubled (pink) 2.6-6.9; minimum 2.58. Circles = 12C/13C 40-100, triangles = 20-200. x axis = density/path-length prior: any n; n >= 6e3 (log n >= 3.8); n >= 1.6e4 (log n >= 4.2); flat log n 3-6; path length L <= 450 or 100 pc with [HCO+]/[H2] <= 1e-8 (3e-9 in the last cell).
**Model facts:** data = HCN, HCO+ 1-0 and 3-2, H13CN and H13CO+ 1-0 at N and S in one 2.2" circular beam, +-150 km/s (1-0: 2015.1.00993 X961; 3-2: 12m+7m from 2017.1.00379 Xb4d+Xb4f, 1 of 2 12-m and 3 of 14 7-m EBs); RADEX LVG slab, one zone per nucleus, one beam-filling factor (ln eta <= 0, flat) common to all lines at that nucleus (equal filling), no core+envelope. Flat priors in log Tk (10-300 K), log n (3-8), log N(HCO+) (13-18), log A (-0.5 to 1.0), 12C/13C = X log-flat 40-100 (default) or 20-200; 3-2/1-0 band-scale nuisance (+-10%, 3 points); sigma^2 = stat^2 + (0.05 I_obs)^2 + (0.10 I_model)^2 (default; halved/doubled = 0.025/0.05 and 0.10/0.20). Bayes factors are exact grid sums and include Occam penalties; they depend mainly on the error model and the 12C/13C prior and are not a proof that excitation differences are excluded (H_exc has BF 0.03-4 against H_full). The alternative branch of a different 12C/13C at S is not excluded (p0062).
