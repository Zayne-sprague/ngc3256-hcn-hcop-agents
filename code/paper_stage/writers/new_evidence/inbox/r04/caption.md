Velocity is relative to 2780 km/s. The windows were defined about 2753 km/s, so they appear at -27 km/s offsets: line window +-350 km/s (yellow), adopted baseline windows -850..-450 and +450..+600 km/s (blue), extra window of variant C -1400..-1150 (green), weak extra HCO+ line at -1100..-900 km/s (orange, marked), and the rejected uv-plane variant-B window -1300..-700 km/s (hatched). Fitted baselines: A adopted (both windows, linear; solid black), blue-only -850..-450 (order 0; dashed), C (dotted). They are nearly indistinguishable at this scale. Cube coverage ends at about +680 km/s.

Bottom left: N-core HCN/HCO+ 3-2 (moment-0 ratio, +-350 km/s, 0.30" beam, r<0.15") for each image-plane baseline variant: A 0.97, order-0 0.98, C 0.97, blue-only 0.99, red-only 0.94, pipeline subtraction only 0.99. Bottom right (text, not recomputed here): in the Xb4d+ACA uv fit, variant A (blue -1300..-700 + red >+560 km/s) gives reduced chi2 5.5 and N(0.4") = 0.96.
