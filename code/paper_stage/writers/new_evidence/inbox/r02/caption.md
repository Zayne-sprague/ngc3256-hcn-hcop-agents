Black line = 1; grey band = Harada+2018 (ApJ 855, 49, Table 13) HCN/HCO+ N/S = 1.48 at 1.7" in **J=1-0** (recomputed from the table integrals: 1.49 +-0.02 stat; band drawn at +-0.03 and spans all beams, it is a single-beam value). † = beam or estimator differs from the main series (see flags).
